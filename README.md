a long time on Bitbucket in Mercurial repositories. They have been moved here
to GitHub after Bitbucket dropped support for Mercurial.

Recently I ported these Python simulators to Typescript, and you can play with them
in your browser at [ww2crypto.online](https://ww2crypto.online).

I also created [SurfGuitar101.com](https://surfguitar101.com), a community website
for friends and fans of instrumental surf music. The site is created in Python using
the Django web framework, Redis, and PostregeSQL.

In my previous life I was a real-time embedded systems programmer, mostly
using C++ and C.

I'm interested in Python, Django, Typescript, web development, Dart, & Flutter.
